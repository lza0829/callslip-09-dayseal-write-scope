# 叫号条（Callslip）

银行网点柜面叫号：取号入队 → 叫号推进 → 过号回收/重叫 → 当日队列封口。

- 前端 http://127.0.0.1:6400
- API http://127.0.0.1:11400
- `docker compose up -d --build`

## 日切封口 · 全日号牌写闸

本系统全局只贯彻一种封口架构：**全日号牌写闸**（不混用"仅禁新发号"口径）。

- 封口成功后，当日一切号牌写——发号、叫号、重叫、过号、办结、作废与号段游标推进——一律拒绝（400，全系统统一文案）；总览、等候墙、列表等只读接口仍可用。
- 臂内解封：`POST /api/日切/解封` 向当日追加解封事件，写闸重开。
- 闸态事实源：`day_seal_events` 追加事件流（只增不改）。`已封口` 与发号闸、叫号闸等各口闸态全部由事件重放得出，`GET /api/日切/事件` 可外部重放验证；系统内不存在第二份开关标志，日切页、各写口、总览同刷一致。
- 并发：所有写口在 `BEGIN IMMEDIATE` 事务内先过闸再落写，封口与发号/叫号互斥——已封不能写，写半截不存在。
- 号牌按（营业日， 号牌）唯一：号段游标跨日重置后，新营业日发同段号不被旧日记录误挡。
